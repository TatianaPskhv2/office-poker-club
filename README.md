# Office Poker Club

Веб-приложение для любительских покерных игр в офисе: планирование столов, запись, рейтинг, карточки игроков и история.

Интерфейс на русском языке. По умолчанию используется тёмная графитовая тема, данные живут в mock-режиме с сохранением в `localStorage`. Слой Supabase уже подготовлен и включается переменными окружения.

## Что нужно установить на своём компьютере

На этой машине уже есть Node.js. Если запускаете проект локально, установите:

1. **Node.js 20+** — [https://nodejs.org](https://nodejs.org)
2. **npm** идёт вместе с Node.js (`npm -v` должен работать)
3. Опционально **Git**

Проверка:

```bash
node -v
npm -v
```

Затем в папке проекта:

```bash
npm install
```

Если `npm install` ругается на сеть или права — обновите npm:

```bash
npm install -g npm
```

Supabase CLI для этого проекта не обязателен: приложение работает без облачной базы.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:4321](http://127.0.0.1:4321).

Для коллег нужен публичный адрес, не `127.0.0.1`. Сайт публикуется на GitHub и Netlify; после деплоя задайте `PUBLIC_APP_URL`.

Сборка и проверка:

```bash
npm run lint
npm run build
```

## Возможности

- Дашборд ближайшей игры и статистики команды
- Календарь / список игр, фильтры и поиск
- Создание игры с валидацией Zod
- Запись и отмена записи
- Страница игры, отмена, результаты
- Карточки и профили участников
- Рейтинг с периодами и графиком
- Живой стол Texas Hold'em: ссылка за стол, банки, выбытие, рейтинг
- История и экспорт CSV
- Роли admin / member / viewer (переключаются в настройках)
- Тёмная и светлая тема

## Mock и Supabase

Пока нет `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`, работает mock-хранилище.

Чтобы переключиться позже:

1. Создайте проект в Supabase
2. Скопируйте `.env.example` в `.env.local`
3. Выполните SQL из `lib/supabase/schema.sql`
4. Замените вызовы `clubActions` на запросы клиента из `lib/supabase/client.ts`

Формула рейтинга живёт в `lib/rating.ts`. Живой стол Hold'em: `/live/[id]`.

## Публикация

Сайт размещён на [Amvera](https://amvera.ru) — серверы в Москве, открывается из РФ без VPN.

Netlify (`office-poker-club.netlify.app`) оставлен как запасной адрес, но из России часто недоступен.
